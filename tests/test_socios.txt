-- POST SOCIOS
Caso 1 — Creación válida
{
  "nombre": "Perez, Juan",
  "email": "jperez@fi.uba.ar"
}
Esperado: 201. activo: true (lo asigna el servidor).

Caso 2 — Email duplicado (bmarani@fi.uba.ar ya existe, socio id 1)
{
  "nombre": "Otro Marani",
  "email": "bmarani@fi.uba.ar"
}
Esperado: 409.

Caso 3 — Email duplicado con mayúsculas/espacios (mismo caso 2, pero disfrazado)
{
  "nombre": "Otro Marani",
  "email": "  BMarani@FI.UBA.AR  "
}
Esperado: 409 — el email se normaliza a minúsculas/sin espacios antes de comparar.

Caso 4 — Nombre vacío
{
  "nombre": "   ",
  "email": "nuevo@fi.uba.ar"
}
Esperado: 400.

Caso 5 — Email con formato inválido
{
  "nombre": "Test Formato",
  "email": "no-es-un-email"
}
Esperado: 400.

Caso 6 — Falta un campo obligatorio
{
  "nombre": "Falta Email"
}
Esperado: 400.

Caso 7 — Body vacío
{}
Esperado: 400.

Caso 8 — Campo desconocido
{
  "nombre": "Con Telefono",
  "email": "contelefono@fi.uba.ar",
  "telefono": "1122334455"
}
Esperado: 400.

Caso 9 — Intenta pisar "activo" en la creación
{
  "nombre": "Quiere Ser Inactivo",
  "email": "inactivo@fi.uba.ar",
  "activo": false
}
Esperado: 400 — "activo" no es un campo permitido en la creación (lo asigna el servidor en true).


-- GET SOCIOS/{ID}
Caso 1 — Id existente
URL: http://localhost:8080/club_deportivo_encuentro/socios/1
Esperado: 200.

Caso 2 — Id inexistente
URL: http://localhost:8080/club_deportivo_encuentro/socios/9999
Esperado: 404.

Caso 3 — Id no numérico
URL: http://localhost:8080/club_deportivo_encuentro/socios/hola
Esperado: 404 (no matchea la ruta <int:id_socio>, es el 404 genérico de Flask, no el de "socio no encontrado").
